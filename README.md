# 🚀 Personal Web Project (Bootstrap 5 + Docker)

โปรเจกต์พัฒนาเว็บไซต์ส่วนตัวด้วย **Bootstrap 5**, **Vite** และรันผ่าน **Docker Desktop**

## 🛠️ Tech Stack
* **Frontend:** Bootstrap 5.3, Sass/SCSS, HTML5
* **Build Tool:** Vite
* **Containerization:** Docker Desktop & Docker Compose
* **Environment:** Node.js 20 (Alpine)

## 💻 วิธีการรันโปรเจกต์ (How to Run)

1. เปิดโปรแกรม **Docker Desktop** ให้พร้อมทำงาน
2. Clone โปรเจกต์นี้ลงเครื่อง:
   ```bash
   git clone https://github.com/boonyahutanoonj-coder/bootstrap-docker-681310498.git
   cd my-bootstrap-lastes
   ```
3. สั่งรันด้วย Docker Compose:
   ```bash
   docker compose up --build
   ```
4. เปิดใช้งานผ่านเบราว์เซอร์ที่:
   - หน้าหลัก (ประวัติ/แนะนำตัว): [http://localhost:5173/](http://localhost:5173/)
   - หน้าเมนูอาหาร: [http://localhost:5173/article.html](http://localhost:5173/article.html)
